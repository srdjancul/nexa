# Nexa

A modernized rebuild of the Nicaea Framer template as a Next.js site.

**Stack:** Next.js (App Router) · TypeScript · Tailwind CSS v4 · Vercel

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
